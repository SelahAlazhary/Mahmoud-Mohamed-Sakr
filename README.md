# أ.د. محمود محمد صقر — أسئلة الحضور

صفحة تعريفية بالأستاذ الدكتور محمود محمد صقر مع نموذج لتسجيل أسئلة الحضور وإرسالها إلى بوت تليجرام.

**المؤتمر السنوي للجمعية المصرية لأبحاث السرطان (EACR) — 2026، المركز القومي للبحوث.**

## ١) شعار الجمعية
ضع شعار الجمعية المصرية لأبحاث السرطان داخل هذا المجلد باسم **`eacr-logo.png`**.
الصفحة تجرّب أيضاً: `eacr-logo.jpg` ← `eacr.png` ← `eacr.jpg` ← `logo.png` ← `logo.jpg`،
ويظهر الشعار في الشريط العلوي وفي التذييل. وإن لم يوجد، تعرض أيقونة بديلة.

## ٢) الصورة الرسمية
احفظ صورة الدكتور داخل هذا المجلد باسم **`sakr.jpg`**.
الصفحة تجرّب تلقائياً: `sakr.jpg` ← `sakr.jpeg` ← `sakr.png` ← `sakr.webp` ← `photo.jpg`.
لو لم تجد أي ملف، تعرض إطاراً بديلاً برموز الاسم بدل الصورة.

## ٣) ربط بوت تليجرام
افتح `index.html` واملأ القيم في أعلى وسم `<script>`:

```js
var CONFIG = {
  BOT_TOKEN: "123456:AA...",   // التوكن من BotFather
  CHAT_ID:   "-1001234567890", // معرّف المحادثة/القناة التي تصل إليها الأسئلة
  BOT_USERNAME: "MyBot"        // اسم البوت بدون @ (اختياري)
};
```

### كيف تحصل عليهما
1. أرسل `/newbot` إلى **@BotFather** واحصل على `BOT_TOKEN`.
2. لمعرفة `CHAT_ID`: أرسل رسالة إلى البوت (أو أضِفه مشرفاً في قناة وانشر رسالة)، ثم افتح:
   `https://api.telegram.org/bot<TOKEN>/getUpdates`
   وخذ قيمة `chat.id`.

## ٤) قبل الضبط
قبل إدخال التوكن، الزر ينسخ نص السؤال إلى الحافظة ويفتح محادثة البوت (لو ضُبط `BOT_USERNAME`) — أي أن الصفحة تعمل ولا تتعطل.

## ⚠ ملاحظة أمنية
وضع `BOT_TOKEN` داخل الصفحة يجعله مقروءاً لأي شخص يفتح كود المصدر.
هذا مقبول لبوت مخصّص للمؤتمر فقط. للاستخدام العام، مرّر الطلب عبر دالة وسيطة على الخادم
(مثل Vercel Function) واحتفظ بالتوكن في متغيّر بيئة.
